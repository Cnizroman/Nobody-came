# Nobody came — Web Storytelling

> Интерактивный литературный веб-проект **«Nobody came» / «Никто не вспомнит»**.

Сайт объединяет авторские истории, интерактивное чтение, атмосферный интерфейс и систему рецензий.

## 📚 Структура проекта

### Тетралогия

**«Nobody came» — это тетралогия из четырёх книг:**

1. **Дорога из Холода**
2. **Спасательный круг**
3. **Там, где нас нет**
4. **7 Дней**

### Отдельные истории

После тетралогии размещаются самостоятельные произведения, которые **не являются частью тетралогии**.

Сейчас среди них:

- **Белая голова**

## ⭐ Система рецензий

Каждая книга и отдельная история имеет собственную оценку.

| Критерий | Максимум |
|---|---:|
| Сюжет | 5 |
| Персонажи | 4 |
| Атмосфера | 4 |
| Язык и стиль | 4 |
| Эмоциональное воздействие | 4 |
| **Итого** | **21** |

Итоговая оценка рассчитывается автоматически из пяти критериев.

**Оценки разных произведений не объединяются.**

## 🔐 Администрирование

Для модерации рецензий используется:

```text
reviews-admin.html
```

Администратор может:

- просматривать новые рецензии;
- публиковать их;
- отклонять их;
- удалять обработанные рецензии.

Доступ администратора контролируется через Supabase Authentication и таблицу `review_admins`.

> Защита страниц, реализованная на стороне браузера, не является полноценной серверной системой безопасности.

## 🗄️ Supabase

Система рецензий использует Supabase для хранения данных.

Основные таблицы:

- `reviews` — рецензии пользователей;
- `review_admins` — администраторы.

Статусы рецензий:

```text
PENDING
PUBLISHED
REJECTED
```

Только опубликованные рецензии отображаются посетителям и учитываются в статистике произведения.

## 🎨 Концепция

Проект задуман как интерактивное литературное пространство, где сайт является частью повествования, а не просто страницей с текстом.

В оформлении используются:

- тёмные фоны;
- контрастная типографика;
- архивные элементы;
- интерактивные панели;
- диалоговые блоки;
- атмосферные цветовые акценты.

Разные истории могут иметь собственное визуальное оформление, сохраняя общую структуру проекта.
