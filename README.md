# Nobody came — Web Storytelling

> Интерактивный литературный веб-проект **«Nobody came» / «Никто не вспомнит»**.

Сайт объединяет авторские истории, интерактивное чтение, атмосферный интерфейс и систему рецензий.

## 📚 Структура проекта

### Тетралогия

**«Nobody came» — это тетралогия из четырёх книг:**

1. **Дорога из Холода**
2. **Спасательный круг**
3. **Там, где нас нет**
4. **7 Дней**

### Отдельные истории

После тетралогии размещаются самостоятельные произведения, которые **не являются частью тетралогии**.

## ⭐ Система рецензий

Каждая книга и отдельная история имеет собственную оценку.

| Критерий | Максимум |
|---|---:|
| Сюжет | 5 |
| Персонажи | 4 |
| Атмосфера | 4 |
| Язык и стиль | 4 |
| Эмоциональное воздействие | 4 |
| **Итого** | **21** |

Итоговая оценка рассчитывается автоматически из пяти критериев.

**Оценки разных произведений не объединяются.**

## 🔐 Администрирование

Для модерации рецензий используется:

```text
reviews-admin.html
```

Администратор может:

- просматривать новые рецензии;
- публиковать их;
- отклонять их;
- удалять обработанные рецензии.

Доступ администратора контролируется через Supabase Authentication и таблицу `review_admins`.

> Книга 3 защищена паролем через шифрование: текст хранится в странице только в зашифрованном виде (AES-256-GCM, ключ из пароля через PBKDF2, 600 000 итераций) и расшифровывается в браузере после ввода пароля. Это намного надёжнее, чем прежняя проверка, но стойкость зависит от длины пароля: короткое слово подбирается быстрее, чем длинная фраза.

## 🗄️ Supabase

Система рецензий использует Supabase для хранения данных.

Основные таблицы:

- `reviews` — рецензии пользователей;
- `review_admins` — администраторы.

Статусы рецензий:

```text
PENDING
PUBLISHED
REJECTED
```

Только опубликованные рецензии отображаются посетителям и учитываются в статистике произведения.


## 🔎 SEO и служебные файлы

- `robots.txt` — разрешает индексацию, закрывает `reviews-admin.html` и `secret.html`;
- `sitemap.xml` — карта сайта (если добавляешь страницу, добавь её и сюда);
- `manifest.webmanifest` + иконки в `assets/` — установка сайта как приложения на телефон;
- `assets/og-image.png` — картинка для превью ссылки в соцсетях и мессенджерах;
- у каждой публичной страницы есть `canonical`, Open Graph и своё описание.

## ⚡ Скорость и офлайн

- Библиотека Supabase подгружается только когда читатель долистал до отзывов или решил написать свой;
- `sw.js` (service worker) сохраняет посещённые страницы: прочитанное открывается без сети. Стратегия «сначала сеть», поэтому новые главы доходят до читателей сразу. Чтобы сбросить кеш у всех, увеличь номер версии `CACHE` в `sw.js`.

## 🔐 Как поменять пароль книги 3

Текст лежит в `book3.html` в блоке `locked-data` только в зашифрованном виде, поэтому пароль нельзя просто переписать в коде. Нужно заново зашифровать исходный текст новым паролем (шифрование — AES-GCM, PBKDF2-SHA256, 600 000 итераций, 16 байт соли, 12 байт IV; в `locked-data` лежат две версии: `n` — полная, `b` — «с начала»).

## 🎨 Концепция

Проект задуман как интерактивное литературное пространство, где сайт является частью повествования, а не просто страницей с текстом.

В оформлении используются:

- тёмные фоны;
- контрастная типографика;
- архивные элементы;
- интерактивные панели;
- диалоговые блоки;
- атмосферные цветовые акценты.

Разные истории могут иметь собственное визуальное оформление, сохраняя общую структуру проекта.

## 🎭 Визуальный слой

Оформление живёт в двух местах и не влияет на логику:

- `visuals.js` — атмосфера, появление блоков, подсветка, липкая шапка, таймлайн, цитаты;
- конец `style.css` — блок `NOBODY CAME — VISUAL LAYER v3` со всеми новыми стилями.

Правила слоя:

- ничего не ломается без JS (если скрипт не загрузится, страница просто остаётся статичной);
- при `prefers-reduced-motion: reduce` все анимации и частицы отключаются;
- на сенсорных устройствах отключаются подсветка и наклон карточек;
- частицы не рисуются, когда вкладка скрыта.

Если меняешь `visuals.js` или `style.css`, увеличь номер версии `CACHE` в `sw.js`.
