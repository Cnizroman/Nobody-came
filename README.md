# ✒ Чернила — гигантская платформа для авторов

**«Чернила»** — тёмная литературная платформа для авторов рассказов, романов, повестей, стихотворений, эссе и всего, что пишется буквами. Место, где истории находят читателей, а авторы — друг друга.

> Никого не вспомнят. Пока он не напишет.

Платформа выросла из личного сайта **Cnizroman** «Никто не вспомнит»: автор стал основателем и первым автором «Чернил», а его тетралогия и «Белая голова» — первыми произведениями каталога. Секретные/пасхальные истории старого сайта полностью удалены.

- **Сайт:** https://cnizroman.github.io/Nobody-came/
- **Стек:** HTML, CSS, JavaScript (SPA без сборки), Supabase (Auth + Postgres + RLS), GitHub Pages

## ✨ Что умеет платформа

**Для читателей**
- Каталог с фильтрами: тип (роман, рассказ, повесть, стихи, эссе, сборник, фанфикшн, пьеса, дневник), жанр, статус, сортировка и полнотекстовый поиск.
- Страница произведения: обложка, аннотация, статистика, главы, похожие произведения.
- Читалка: темы «Тьма / Бумага / Свет», размер шрифта, прогресс чтения, комментарии к главам.
- Личная полка: «Хочу прочитать», «Читаю», «Прочитано», «Избранное», продолжить чтение.
- Подписки на авторов и лента новых глав.
- Рецензии по фирменной системе пяти критериев (наследство проекта Cnizroman): сюжет — до 5, персонажи, атмосфера, язык и стиль, эмоции — до 4; **максимум 21 балл**.

**Для авторов**
- Регистрация и профиль автора со значками достижений.
- Студия автора: статистика и график читательской активности, произведения, черновики.
- Редактор глав: форматирование, счётчик слов и времени чтения, автосохранение черновика, порядок глав.
- Генератор обложек (градиенты и символы), теги, возрастной рейтинг, статусы.
- Конкурсы платформы («Первая строка», «Ночной сад» и др.).

**Для администратора** — модерация рецензий и комментариев, «Выбор платформы» на главную.

## 🚀 Запуск локально

```bash
python -m http.server 8000
# http://localhost:8000
```

Демо-вход в локальном режиме: логин любого автора из каталога (например, `cnizroman`), пароль `demo1234`.

## 🗄️ Подключение Supabase (общая база)

Без настройки сайт работает в **локальном режиме** на `localStorage`. Для настоящей общей платформы выполните один SQL-файл — пошагово в [`SUPABASE_PLATFORM_SETUP.md`](SUPABASE_PLATFORM_SETUP.md):

1. SQL Editor → вставить [`supabase-platform-schema.sql`](supabase-platform-schema.sql) → Run.
2. Authentication: настроить Email и Redirect URL сайта.
3. Зарегистрироваться на сайте и одной командой SQL назначить себя основателем-админом.

Старая таблицы `reviews` и панель `reviews-admin.html` не трогаются и продолжают работать.
