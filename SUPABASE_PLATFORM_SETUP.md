# «Чернила» — подключение общей базы Supabase (5 минут)

Сайт уже работает в локальном режиме (данные в браузере каждого посетителя).
Чтобы все авторы и читатели видели **одну общую платформу** — настоящие аккаунты,
произведения, рецензии и подписки — выполните три шага. Проект Supabase тот же,
что использовался для рецензий книг; старые таблицы не пострадают.

## Шаг 1. Выполните SQL

1. Откройте свой проект на [supabase.com](https://supabase.com) → **SQL Editor** → **New query**.
2. Вставьте целиком файл [`supabase-platform-schema.sql`](supabase-platform-schema.sql) и нажмите **Run**.

Создадутся таблицы: `profiles`, `works`, `chapters`, `comments`, `work_reviews`,
`likes`, `shelves`, `follows`, `contests`, `contest_entries` — все с Row Level Security.

## Шаг 2. Настройте регистрацию

**Authentication → Providers → Email**:

- Если хотите вход без подтверждения почты — отключите **Confirm email**.
- Если оставите подтверждение включённым, после регистрации автор получит письмо
  и войдёт по ссылке из него (сайт об этом честно сообщит).

**Authentication → URL Configuration**: в Redirect URLs добавьте адрес сайта:
`https://cnizroman.github.io/Nobody-came/`

## Шаг 3. Станьте основателем платформы

1. Зарегистрируйтесь на сайте («Стать автором») с логином `cnizroman`.
2. В SQL Editor выполните:

```sql
update public.profiles
set role = 'admin', is_founder = true,
    badges = array['Основатель платформы','Первый автор']
where username = 'cnizroman';
```

Вам откроется «⚖ Модерация платформы» в студии автора.

3. Заведите книги тетралогии через Студию автора (или одним SQL из комментариев
   в конце схемы), указав в `legacy_url`: `intro.html`, `book1.html`, `book2.html`,
   `book3.html`, `book4.html`, `belaya-golova.html` — полные тексты продолжат
   открываться в исходной читалке.

## Как платформа выбирает режим

При загрузке сайт проверяет таблицу `works`:

- таблица существует → **режим Supabase**: аккаунты, публикация, лайки, полки,
  подписки, конкурсы — всё пишется в общую базу;
- таблицы нет → **локальный режим**: всё работает на `localStorage`,
  сверху показывается золотая плашка. Сайт никогда не выглядит сломанным.

## Безопасность

- В `supabase-config.js` — только публичный publishable key. Никогда не кладите
  туда `service_role`/`secret`.
- Все права заданы политиками RLS: автор меняет только своё, черновики видит
  только автор, полки видит только владелец, админ определяется полем
  `profiles.role = 'admin'`.
- Старая система рецензий (таблица `reviews`, `reviews-admin.html`) не тронута
  и продолжает работать для книг первого автора.
