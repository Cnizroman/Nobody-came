# «Чернила»: владельцу осталось ОДНО действие

Платформа полностью готова и уже работает. Единственное, чего сайт не может
сделать сам (у него нет и не должно быть секретного ключа от вашей базы), —
**выполнить один готовый SQL-файл в Supabase**. На сайте для этого есть
страница **«Запуск общей базы»** (`#/setup`) с кнопками «Скопировать SQL»
и прямой ссылкой в SQL Editor именно вашего проекта.

## Одно действие (2 минуты)

1. На сайте откройте `#/setup` → **Скопировать SQL**.
2. Там же → **Открыть SQL Editor проекта**, вставьте, нажмите **Run**.
3. Вернитесь и нажмите «Проверить подключение».

## Всё остальное автоматизировано в самом SQL и коде

- Сайт сам определяет готовую базу и переключается на неё.
- Профиль автора создаётся триггером при регистрации.
- Подтверждение почты происходит автоматически — настраивать
  Authentication в панели **не нужно**.
- Аккаунт с логином **`cnizroman`** автоматически становится основателем
  и администратором с нужными значками. Зарегистрируйтесь с этим логином
  первым после запуска SQL.
- Книги первого автора (тетралогия и «Белая голова») встроены в платформу:
  вносить их в базу не нужно ни сейчас, ни потом.
- Конкурсы создаются тем же SQL-файлом. Файл идемпотентен: его можно
  запускать повторно без вреда.

## Если действие не выполнить

Сайт продолжить работать в локальном режиме: каталог только с книгами
Cnizroman, студия, рецензии и полки функционируют, но данные каждого
посетителя хранятся в его собственном браузере и не видны остальным.

## Безопасность

В `supabase-config.js` — только публичный publishable key. Все права —
политиками RLS: автор меняет только своё, черновики видит только автор,
полки — только владелец, админ — `profiles.role = 'admin'` (выдаётся
автоматически логину `cnizroman`). Старая система рецензий книг
(`reviews`, `reviews-admin.html`) не тронута.
